راهنمای ساخت اپلیکیشن قبله‌نما (Android Studio)
===================================================

این یک پروژهٔ کامل و آماده اندروید استودیوئه. صفحهٔ قبله‌نما به‌صورت
یک WebView داخل اپ لود می‌شه و مجوز موقعیت مکانی (ACCESS_FINE_LOCATION)
از قبل داخل AndroidManifest.xml قرار داده شده و در کد جاوا هم مدیریت
شده که وقتی صفحه HTML درخواست GPS می‌کنه، پاپ‌آپ رسمی اندروید نشون
داده بشه.

مراحل ساخت APK:
----------------
۱. Android Studio رو نصب کنید (رایگانه): https://developer.android.com/studio

۲. از منوی File > Open، همین پوشهٔ QiblaCompassApp رو انتخاب کنید.

۳. صبر کنید تا Gradle Sync تموم بشه (بار اول ممکنه چند دقیقه طول
   بکشه و به اینترنت نیاز داره تا وابستگی‌ها رو دانلود کنه).
   اگر پیغامی دربارهٔ "Gradle wrapper" دیدید که ازتون می‌خواد
   wrapper رو بسازه یا دانلود کنه، گزینهٔ تایید/OK رو بزنید.

۴. از منوی Build > Build Bundle(s) / APK(s) > Build APK(s) رو بزنید.

۵. بعد از اتمام Build، لینک "locate" که پایین صفحه ظاهر می‌شه رو
   بزنید تا فایل APK رو پیدا کنید (معمولاً در مسیر:
   app/build/outputs/apk/debug/app-debug.apk)

۶. این فایل APK رو به گوشی اندرویدتون منتقل کنید و نصبش کنید
   (شاید لازم باشه "Install from unknown sources" رو در تنظیمات
   امنیتی گوشی فعال کنید).

۷. اپ رو باز کنید، دکمهٔ "درخواست دسترسی و شروع" رو بزنید. این بار
   باید پاپ‌آپ رسمی اندروید برای اجازهٔ موقعیت مکانی بیاد. روی
   Allow بزنید.

ساختار پروژه:
--------------
- app/src/main/AndroidManifest.xml   -> مجوزهای اپ (از جمله ACCESS_FINE_LOCATION)
- app/src/main/java/.../MainActivity.java -> کد WebView و مدیریت مجوز GPS
- app/src/main/assets/index.html     -> کد کامل قبله‌نما (HTML/CSS/JS)
- app/src/main/res/layout/activity_main.xml -> چیدمان صفحه (فقط یک WebView تمام‌صفحه)

نکته دربارهٔ آیکون اپ:
------------------------
این پروژه از آیکون پیش‌فرض اندروید استفاده می‌کنه. اگه می‌خواید آیکون
اختصاصی (طلایی/سرمه‌ای که قبلاً ساختم) رو جایگزین کنید، کافیه فایل‌های
icon-192.png و icon-512.png رو در Android Studio، با کلیک راست روی
پوشهٔ res و انتخاب New > Image Asset، به‌عنوان Launcher Icon وارد کنید.

نکتهٔ فنی:
----------
سنسور جهت‌یاب (قطب‌نما) نیازی به مجوز خاصی در اندروید نداره و باید
خودکار کار کنه. اگه گوشی سنسور مگنتومتر نداشته باشه (به‌ندرت پیش
میاد)، صفحه پیام "سنسور قطب‌نما یافت نشد" رو نشون می‌ده.
